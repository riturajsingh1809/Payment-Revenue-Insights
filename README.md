# Payment Revenue Insights Dashboard

*Developed by Ritu Raj Singh*

## Project Overview

This project analyzes payment transactions to define and monitor key revenue metrics, payment performance, gateway efficiency, and transaction outcomes.

The objective is to transform payment data into clear business insights that can support revenue monitoring and payment performance decisions.

## Project Workflow

*Raw Data → Excel Cleaning → Python Analysis → Tableau Dashboard → Business Insights*

## Data Cleaning

The raw dataset was cleaned and prepared using *Microsoft Excel*.

The cleaning process included:

* Removing duplicate records
* Handling missing values
* Standardizing categorical values
* Correcting date and numeric formats
* Checking invalid values
* Validating the final dataset for data quality

The cleaned dataset was then used for analysis and visualization.

## Python Analysis

Python was used in Google Colab for analytical processing using Pandas and NumPy.

The analysis focused on:

* Total transaction value
* Successful revenue
* Payment success and failure rates
* Refund and pending transactions
* Gateway performance
* Payment method performance
* Regional revenue
* Monthly revenue trends
* Processing time
* Customer-level payment analysis

The analysis results were consolidated into a single Excel output file.

## Tableau Dashboard

An interactive Tableau dashboard was created to monitor:

* Revenue KPIs
* Payment status
* Gateway performance
* Gateway success rate
* Payment method performance
* Monthly revenue
* Regional revenue
* Processing time

Filters allow users to explore payment performance across different dates, gateways, methods, regions, and customer types.

## Key Business Objective

The dashboard helps identify payment performance issues, understand revenue contribution, compare payment gateways and methods, and support data-driven decisions.

## Tools Used

## Project Outcome

The project delivers a decision-oriented payment analytics solution where revenue metrics can be traced to the underlying payment data and monitored through an interactive Tableau dashboard.
